Who we are

Built from the client side of the table

Gate79 started in 2021, after our founder spent a decade running e-commerce for product brands and hiring agencies. The pattern was always the same: an ads team that never read the listing, and a monthly call that explained everything except the number.

So we run the channel as one system. The same people plan the keywords, brief the photography, set the bids, forecast the stock and write the report. When a number moves, we know which lever moved it.

  • The audit is scored: under 79, it goes back to the desk
